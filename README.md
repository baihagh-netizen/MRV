# Pension User - مرحله‌ای

- صفحه آغازین با سربرگ آبی و عنوان «محاسبه مستمری بازنشستگی (NIOC)»
- فونت نستعلیق در `app/src/main/assets/fonts/IranNastaligh.ttf`
- صفحه معرفی تهیه‌کننده و سپس استاد راهنما
- ورود اطلاعات تک‌به‌تک با دکمه‌های Next و Back؛ اطلاعات هنگام بازگشت حفظ می‌شوند.
- صفحه محاسبه و صفحه نتیجه با امکان بازگشت برای اصلاح اطلاعات

## نکته امنیتی
فایل‌های داخل APK برای کاربر عادی در دسترس مستقیم نیستند، اما APK را می‌توان استخراج و بررسی کرد. این پروژه سورس را به‌صورت رمزنگاری‌شده یا غیرقابل‌بازیابی قفل نمی‌کند؛ برای حفاظت قوی‌تر باید منطق حساس محاسبه به کد بومی منتقل شود.
